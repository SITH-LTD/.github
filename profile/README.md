# SITH R&D Center

**SITH R&D Center** is the software research and development organization of **SITH-LTD**, focused on secure software development, system integration, API services, and engineering governance.

---

## Mission

Our mission is to support the design, development, integration, and continuous improvement of information systems through reliable engineering practices, secure development processes, and maintainable system architecture.

## Focus Areas

* Secure software development lifecycle practices
* Enterprise system integration
* API design and service governance
* Internal application modernization
* DevOps, automation, and deployment standardization
* Code quality, testing, and maintainability improvement
* Technical documentation and knowledge management

## Engineering Principles

* Security by design and by default
* Maintainable and reviewable code
* Clear system boundaries and responsibilities
* Standardized development and deployment processes
* Traceable requirements, changes, and decisions
* Continuous improvement through testing, review, and automation

## Repository Usage

Repositories under this organization are used for software development, system integration, technical research, automation scripts, internal tools, and engineering documentation managed by the SITH R&D Center.

# 翔生資訊軟體研發中心

**翔生資訊軟體研發中心**為 **SITH-LTD** 所屬之軟體研發組織，主要負責安全軟體開發、系統整合、API 服務設計，以及工程治理與研發流程標準化。

---

## 使命

本中心致力於透過可靠的工程實務、安全開發流程與可維護的系統架構，支援資訊系統之設計、開發、整合與持續改善。

## 主要工作範圍

* 安全軟體開發生命週期實務
* 企業系統整合
* API 設計與服務治理
* 內部應用系統現代化
* DevOps、自動化與部署標準化
* 程式碼品質、測試與可維護性改善
* 技術文件與知識管理

## 工程原則

* 預設安全與安全設計
* 程式碼應具備可維護性與可審查性
* 明確定義系統邊界與責任歸屬
* 標準化開發與部署流程
* 需求、異動與決策應可追溯
* 透過測試、審查與自動化持續改善

## Repository 使用說明

本組織下之 repositories 主要用於軟體開發、系統整合、技術研究、自動化腳本、內部工具與工程文件管理。
