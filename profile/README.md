# SITH-LTD

**SITH-LTD** is an information technology and software engineering organization focused on secure system development, enterprise integration, application modernization, and engineering governance.

---

## About

SITH-LTD supports the planning, development, integration, operation, and continuous improvement of enterprise information systems through reliable engineering practices, security-oriented design, and standardized development processes.

## Focus Areas

* Secure software development lifecycle practices
* Enterprise application development and integration
* API design and service governance
* System modernization and maintainability improvement
* DevOps, automation, and deployment standardization
* Code quality, testing, and technical documentation
* Engineering governance and knowledge management

## Engineering Principles

* Security by design and by default
* Maintainable, reviewable, and traceable code
* Clear system boundaries and responsibilities
* Standardized development, testing, and deployment processes
* Continuous improvement through review, automation, and documentation

## Repository Usage

Repositories under this organization are used for software development, system integration, technical research, automation scripts, internal tools, and engineering documentation.

# 翔生資訊

**翔生資訊**為資訊技術與軟體工程組織，主要聚焦於安全軟體開發、企業系統整合、應用系統現代化，以及工程治理與研發流程標準化。

---

## 關於我們

翔生資訊致力於透過可靠的工程實務、安全導向設計與標準化開發流程，支援企業資訊系統之規劃、開發、整合、維運與持續改善。

## 主要工作範圍

* 安全軟體開發生命週期實務
* 企業應用系統開發與整合
* API 設計與服務治理
* 系統現代化與可維護性改善
* DevOps、自動化與部署標準化
* 程式碼品質、測試與技術文件管理
* 工程治理與知識管理

## 工程原則

* 預設安全與安全設計
* 程式碼應具備可維護性、可審查性與可追溯性
* 明確定義系統邊界與責任歸屬
* 標準化開發、測試與部署流程
* 透過審查、自動化與文件化持續改善

## Repository 使用說明

本組織下之 repositories 主要用於軟體開發、系統整合、技術研究、自動化腳本、內部工具與工程文件管理。
